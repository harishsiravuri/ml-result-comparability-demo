Leaderboard Check

Leaderboards rank AI methods by one number. But papers measure that number in different ways. Some use validation data, which researchers use while tuning a method. Others use test data, held back for the final measurement. Ranking the two together is like ranking practice-exam scores with final-exam scores. This page shows the top number next to the best number from a fair comparison.

The questions

Words used here

Validation and test sets
Validation data guide choices while a method is tuned. Test data are kept back for the final measurement. Each is a data split.
Fair comparison
The best recorded number among records that share the setup the question needs. A record of unknown setup stands alone, so it cannot win.
Result record
One value reported for one method, with its paper, split, metric name, unit and source location.
Evaluation setup
The data split, the metric name as written, and the unit of a result record.
Valid comparison set
Result records that share split, metric name and unit. This site calls each set a group.
Comparability determination
One recorded decision about two result records, with its status. Released file and field names keep the older word “certificate”.
Not enough evidence
No two extracted records can be compared under the question, so no answer is given.
Pointers
“Extracted table #N (parser order)” is the position of a table in the parsed paper, counted from 0. It may differ from the paper’s own table number.
