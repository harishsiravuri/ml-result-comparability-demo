About Leaderboard Check

Leaderboards rank one number, but papers measure that number under different setups. This site re-ranks every leaderboard in a frozen Papers with Code archive using only results measured the same way, and shows both answers side by side.

The hand check

Words used here

Validation and test sets
Validation data guide choices while a method is tuned. Test data are kept back for the final measurement. Each is a data split.
Fair comparison
The best recorded number among records that share the setup the question needs. A record of unknown setup stands alone, so it cannot win.
Result record
One value reported for one method, with its paper, split, metric name, unit and source location.
Evaluation setup
The data split, the metric name as written, and the unit of a result record.
Valid comparison set
Result records that share split, metric name and unit. This site calls each set a group.
Comparability determination
One recorded decision about two result records, with its status. Released file and field names keep the older word “certificate”.
No fair comparison possible
No two extracted records can be compared under the question, so no answer is given. This is an answer, not an error.
Pointers
“parsed table N” is the position of a table in the parsed paper, counted from 0 in parser order. It may differ from the paper’s own table number.
